Insertion Sort (Sap xep chen)

Bai thuyet trinh nhom

Cuon xuong de bat dau

Tu y tuong

Y tuong giong sap xep bai trong tay: lay tung la bai va chen vao dung vi tri trong day da sap.

Khi nao nen dung / khong nen dung

Phu hop khi du lieu gan sap, mang nho. Khong phu hop khi du lieu lon.

Thuat toan chi tiet

Buoc 1: i chay tu 1 den n-1.

Buoc 2: key gan bang a[i], j gan bang i-1.

Buoc 3: Trong khi j >= 0 va a[j] > key: dich a[j] sang phai, giam j.

Buoc 4: a[j+1] gan bang key.

So do minh hoa

Mang vi du: 12, 11, 13, 5, 6.

Ban dau

Ma gia & Cai dat C++

procedure InsertionSort(a[0..n-1])   // bat dau thuat toan, a co n phan tu
  for i <- 1 to n-1 do                // i chay tu 1 den n-1
    key <- a[i]                       // luu gia tri dang xet
    j <- i - 1                        // j tro phan tu dung truoc
    while j >= 0 and a[j] > key do    // con phan tu trai lon hon key?
      a[j+1] <- a[j]                  // dich a[j] sang phai
      j <- j - 1                      // lui j sang trai
    end while                        // het dich
    a[j+1] <- key                     // chen key vao cho trong
  end for
end procedure
void insertionSort(int a[], int n) {     // ham C++, mang a, n phan tu
  for (int i = 1; i < n; i++) {          // i tu 1 den n-1
    int key = a[i];                      // luu gia tri dang xet
    int j = i - 1;                       // j = vi tri truoc i
    while (j >= 0 && a[j] > key) {     // trai con lon hon key
      a[j + 1] = a[j];                   // dich sang phai
      j--;                               // giam j
    }
    a[j + 1] = key;                      // chen key
  }
}

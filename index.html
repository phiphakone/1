02

Thuật toán chi tiết

1

Bắt đầu từ i = 1

i chạy từ 1 → n−1

2

Lưu key

key ← a[i], j ← i−1

3

Dịch phần tử

Trong khi j ≥ 0 và a[j] > key: a[j+1] ← a[j]; j ← j−1

4

Chèn key

a[j+1] ← key (chèn vào vị trí đúng)

03

Độ phức tạp

⏱

  • Tốt nhất: O(n)
  • Trung bình: O(n²)

Không gian

  • In-place
  • Chỉ cần biến tạm

Ổn định

Có
  • Stable – giữ thứ tự phần tử bằng nhau

Mã giả & Cài đặt C++

procedure InsertionSort(a[0..n−1])
  for i ← 1 to n−1 do
    key ← a[i]
    j ← i − 1
    while j ≥ 0 and a[j] > key do
      a[j+1] ← a[j]
      j ← j − 1
    end while
    a[j+1] ← key
  end for
end procedure
void insertionSort(int a[], int n) {
  for (int i = 1; i < n; i++) {
    int key = a[i];
    int j = i - 1;
    while (j >= 0 && a[j] > key) {
      a[j + 1] = a[j];
      j--;
    }
    a[j + 1] = key;
  }
}
key: lưu giá trị đang xét để chèn
Vòng while: dịch các phần tử lớn hơn key sang phải
Vị trí j+1: chỗ trống để chèn key
Nếu đã sắp: while không chạy → O(n)

07

Ưu & Nhược điểm

Ưu điểm

  • Ổn định (stable)
  • Hiệu quả với dữ liệu gần sắp xếp
  • Online: có thể sắp khi đang nhận dữ liệu
  • Ít bộ nhớ phụ, dễ cài đặt

Nhược điểm

  • O(n²) trong trường hợp xấu
  • Chậm với mảng lớn và đảo ngược hoàn toàn
  • Nhiều lần dịch chuyển phần tử

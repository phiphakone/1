Insertion Sort (Sắp xếp chèn)

Bài thuyết trình nhóm – khoảng 10 người lần lượt trình bày

Cuộn xuống để bắt đầu

Từ ý tưởng

Ý tưởng giống như sắp xếp bài trong tay: lần lượt lấy từng lá bài và chèn vào đúng vị trí trong dãy đã sắp. Coi phần tử đầu đã sắp xếp. Lấy key bằng a[i], dịch các phần tử lớn hơn key sang phải, rồi chèn key vào vị trí trống vừa tạo.

Thuật toán này ổn định và đặc biệt hiệu quả khi dữ liệu gần như đã sắp sẵn.

Khi nào nên dùng / không nên dùng

Insertion Sort phù hợp khi dữ liệu gần đúng hoặc gần sắp, mảng nhỏ đến trung bình, cần thuật toán ổn định, hoặc cần sắp xếp online (nhận dữ liệu dần). Không phù hợp khi dữ liệu lớn và đảo ngược hoàn toàn, hoặc yêu cầu hiệu suất cao trên tập lớn.

✓ Phù hợp khi

  • Dữ liệu gần đúng / gần sắp
  • Mảng nhỏ đến trung bình
  • Cần thuật toán ổn định
  • Online sorting (sắp xếp trực tuyến)

✗ Không phù hợp khi

  • Dữ liệu lớn và đảo ngược
  • Cần hiệu suất cao

Thuật toán chi tiết

Bước 1: i chạy từ 1 đến n−1 (phần tử đầu coi như đã sắp).

Bước 2: key ← a[i], j ← i−1.

Bước 3: Trong khi j ≥ 0 và a[j] > key: dịch a[j] sang phải (a[j+1] ← a[j]), giảm j.

Bước 4: a[j+1] ← key – chèn key vào vị trí đúng. Nếu mảng đã sắp, vòng while không chạy → đạt O(n).

Sơ đồ minh họa từng bước

Minh họa với mảng 12, 11, 13, 5, 6. Mọi người bấm nút bên dưới để xem từng bước.

Ban đầu

Mã giả & Cài đặt C++

procedure InsertionSort(a[0..n−1])   // bắt đầu thuật toán, a có n phần tử
  for i ← 1 to n−1 do                // i chạy từ 1 đến n−1
    key ← a[i]                       // lưu giá trị đang xét
    j ← i − 1                        // j trỏ phần tử đứng trước
    while j ≥ 0 and a[j] > key do    // còn phần tử trái lớn hơn key?
      a[j+1] ← a[j]                  // dịch a[j] sang phải
      j ← j − 1                      // lùi j sang trái
    end while                        // hết dịch
    a[j+1] ← key                     // chèn key vào chỗ trống
  end for
end procedure
void insertionSort(int a[], int n) {     // hàm C++, mảng a, n phần tử
  for (int i = 1; i < n; i++) {          // i từ 1 đến n−1
    int key = a[i];                      // lưu giá trị đang xét
    int j = i - 1;                       // j = vị trí trước i
    while (j >= 0 && a[j] > key) {     // trái còn lớn hơn key
      a[j + 1] = a[j];                   // dịch sang phải
      j--;                               // giảm j
    }
    a[j + 1] = key;                      // chèn key
  }
}
procedure / hàm: bắt đầu thuật toán sắp xếp chèn
for i ← 1 to n−1: bỏ phần tử đầu vì coi đã sắp
key ← a[i]: cất giá trị đang xét để chèn sau
j ← i−1: đứng ở phần tử bên trái của key
while a[j] > key: còn số lớn hơn key thì dịch tiếp
a[j+1] ← a[j]: dời phần tử sang phải, tạo chỗ trống
j-- : lùi sang trái để xét phần tử tiếp
a[j+1] ← key: đặt key vào đúng vị trí

Ưu điểm

Ổn định, hiệu quả khi dữ liệu gần sắp, ít bộ nhớ phụ.

Nhược điểm

Trường hợp xấu O(n²) — số bước ≈ n × n, chậm khi n lớn.

Kết luận

Insertion Sort ổn định, phù hợp dữ liệu gần đúng. Nhóm em xin cảm ơn thầy cô và các bạn.

Insertion Sort (Sắp xếp chèn)

Bài thuyết trình nhóm

Từ ý tưởng

Ý tưởng giống như sắp bài trên tay. Coi phần tử đầu đã sắp. Lấy phần tử tiếp theo gọi là key, dịch những phần tử lớn hơn key sang phải, rồi chèn key vào chỗ trống.

Thuật toán này ổn định và rất hiệu quả khi dữ liệu gần như đã sắp sẵn.

Khi nào nên dùng / không nên dùng

Nên dùng khi mảng nhỏ hoặc trung bình, khi dữ liệu gần đúng, khi cần thuật toán ổn định, hoặc khi nhận dữ liệu dần, gọi là online sorting.

Không nên dùng khi mảng lớn và đảo ngược hoàn toàn, vì trường hợp xấu vẫn là O(n²). O(n²) nghĩa là số bước khoảng n nhân n. Ví dụ một trăm phần tử thì khoảng mười nghìn bước.

✓ Phù hợp khi

  • Dữ liệu gần đúng / gần sắp
  • Mảng nhỏ đến trung bình
  • Cần thuật toán ổn định
  • Online sorting

✗ Không phù hợp khi

  • Dữ liệu lớn và đảo ngược
  • Cần hiệu suất cao

Thuật toán chi tiết

Bước 1: i chạy từ 1 đến n trừ 1. Phần tử đầu coi như đã sắp.

Bước 2: key gán bằng a của i. j gán bằng i trừ 1.

Bước 3: trong khi j còn lớn hơn hoặc bằng 0 và a của j lớn hơn key, dịch a của j sang phải, rồi giảm j.

Bước 4: a của j cộng 1 gán bằng key, tức là chèn key vào đúng chỗ. Nếu mảng đã sắp sẵn, vòng while không chạy, đạt O(n). O(n) nghĩa là thời gian tăng gần đúng bằng số phần tử, nên nhanh.

Sơ đồ minh họa từng bước

Ví dụ mảng 12, 11, 13, 5, 6.

i bằng 1, key bằng 11, dịch 12 sang phải, chèn 11. i bằng 2, key bằng 13, không cần dịch. i bằng 3, key bằng 5, dịch 11 12 13 rồi chèn 5. i bằng 4, key bằng 6, dịch rồi chèn 6. Kết quả 5, 6, 11, 12, 13.

Mọi người có thể bấm nút để xem từng bước.

Ban đầu

Mã giả & Cài đặt C++

Mã giả và C++ làm cùng một việc. Vòng for lấy từng phần tử. Lưu vào key. Dùng while để dịch phần tử lớn hơn key sang phải. Sau đó chèn key vào chỗ trống.

Trong C++, int key và int j là khai báo số nguyên. j trừ trừ nghĩa là giảm j đi 1.

procedure InsertionSort(a[0..n−1])   // bắt đầu thuật toán, a có n phần tử
  for i ← 1 to n−1 do                // i chạy từ 1 đến n−1
    key ← a[i]                       // lưu giá trị đang xét
    j ← i − 1                        // j trỏ phần tử đứng trước
    while j ≥ 0 and a[j] > key do    // còn phần tử trái lớn hơn key?
      a[j+1] ← a[j]                  // dịch a[j] sang phải
      j ← j − 1                      // lùi j sang trái
    end while
    a[j+1] ← key                     // chèn key vào chỗ trống
  end for
end procedure
void insertionSort(int a[], int n) {     // hàm C++, mảng a, n phần tử
  for (int i = 1; i < n; i++) {          // i từ 1 đến n−1
    int key = a[i];                      // lưu giá trị đang xét
    int j = i - 1;                       // j = vị trí trước i
    while (j >= 0 && a[j] > key) {     // trái còn lớn hơn key
      a[j + 1] = a[j];                   // dịch sang phải
      j--;                               // giảm j
    }
    a[j + 1] = key;                      // chèn key
  }
}

Mô hình ví dụ – Sinh viên

Ứng dụng thực tế: sắp danh sách sinh viên theo điểm tăng dần. Sau khi chạy Insertion Sort: Lê Văn C 6.8 → Nguyễn Văn A 7.5 → Trần Thị B 8.2 → Phạm Thị D 9.0.

Ưu điểm

Ổn định, nghĩa là giữ nguyên thứ tự các phần tử bằng nhau. Hiệu quả khi dữ liệu gần sắp. Hỗ trợ online. Ít bộ nhớ phụ. Dễ cài đặt.

Nhược điểm

Trường hợp xấu vẫn O(n²), chậm khi n lớn. Có nhiều lần dịch chuyển phần tử. Mỗi lần chèn có thể phải dời cả đoạn đã sắp.

Kết luận

Insertion Sort ổn định, phù hợp dữ liệu gần đúng và mảng nhỏ. Nhóm em xin cảm ơn thầy cô và các bạn đã lắng nghe.
